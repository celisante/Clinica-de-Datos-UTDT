# Clinica-de-Datos-UTDT
En este repositorio trabajamos el desafío de la Clínica de Datos de las Maestrías en Políticas Públicas y Economía Urbana de UTDT. Equipo: Florencia Ameri, Agustin Barclay, Nicolas Martin, Leonardo Pennesi, Celina Santellán. Hacemos un análisis de la evolución de los alquileres en la Ciudad autónoma de Buenos Aires
